Cómo conectar la Spotify Web API Real

Spotify no expone directamente el número absoluto de Total Streams acumulados mediante la Web API pública estándar por razones de copyright (solo proporciona la métrica de popularity de 0 a 100 y previews de audio). Sin embargo, para obtener datos en tiempo real existen dos métodos utilizados por la comunidad ARMY:

  1. Método Spotify Web API (Popularidad y Track Info): Crea una app en el portal de desarrolladores de Spotify (Developer Dashboard) para obtener un Client ID y Client Secret. Haz un llamado HTTP GET a https://api.spotify.com/v1/tracks/{id} para refrescar metadata automáticamente.
  2. Método Web Scraping / Kworb integration: Sitios como Kworb o Spotifycharts recopilan métricas diarias. Puedes realizar un fetch a un backend propio (servidor Node.js o PHP) que procese las métricas diarias para pasarlas a este frontend.
